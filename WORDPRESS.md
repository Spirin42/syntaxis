# WordPress для «Синтаксиса» — с нуля

Ты никогда не работал с WordPress. Этот файл — не общая документация, а инструкция именно к нашему сайту: что где нажимать, чтобы появилась книга или статья, и чего лучше не трогать.

---

## 1. Что вообще произошло

Раньше сайт был набором html-файлов: чтобы добавить книгу, надо было скопировать `books/hor-odinochek.html`, поправить в нём текст руками и не забыть добавить книгу ещё в трёх местах (главная, каталог, авторы).

Теперь тот же сайт собирается из базы. Ты заводишь книгу один раз в админке — она сама появляется в каталоге, на главной (если отметишь), в списке авторов и в блоке «читайте дальше» на других страницах.

**Дизайн не изменился ни на пиксель.** Вёрстка, шрифты, CSS-обложки, мозаика этажей — всё то же самое, просто теперь оно заполняется данными, а не переписывается вручную. Проверено машинно: все одиннадцать обложек в HTML совпадают со старым макетом символ в символ.

Что появилось нового и чего в макете не было:

| Что | Адрес |
|---|---|
| Индекс журнала (был в дорожной карте) | `/journal/` |
| Рубрики журнала | `/rubrika/esse/` и т. п. |
| Архивы по жанрам | `/genre/roman/` |
| Поиск по сайту | `/?s=слово` |
| Страница 404 | любой битый адрес |
| RSS-лента | `/feed/` |

Что это стоило: сайт больше нельзя положить на бесплатный статический хостинг. Ему нужен хостинг с **PHP 8 и MySQL** — это обычный «сайтовый» хостинг рублей за 200–400 в месяц. Подробности — в `CHECKLIST.md`.

## 2. Как запустить сайт у себя на компьютере

Локальная копия сайта лежит **не в репозитории**, а отдельно: `~/projects/syntaxis-wp/`. Там сам WordPress и база. В репозитории `~/projects/syntaxis` лежит только наша тема — она подключена в установку симлинком, поэтому правки в репозитории видны на сайте сразу.

**Запуск:** открой Finder, зайди в `~/projects/syntaxis-wp` и дважды кликни `start.command`. Откроется терминал, поднимется база и сервер.

Или из командной строки:

```bash
~/projects/syntaxis-wp/start.command
```

Дальше:

| | |
|---|---|
| Сайт | http://localhost:8080 |
| Админка | http://localhost:8080/wp-admin/ |
| Логин | `admin` |
| Пароль | `sintaksis` |

**Остановить** — `Ctrl+C` в том окне терминала.

Пароль простой намеренно: этот сайт виден только с твоего компьютера, из интернета в него не попасть. На боевом сервере пароль будет другой (см. чек-лист).

База — своя, на порту 3307, данные лежат в `~/projects/syntaxis-wp/db/`. Твой уже установленный MySQL она не трогает и работает независимо от него.

## 3. Что где в админке

Слева меню. Разделы, которые нам нужны:

| Пункт | Что там |
|---|---|
| **Книги** | каталог издательства. Здесь же «Авторы» и «Жанры» |
| **Журнал** | статьи, эссе, интервью. Здесь же «Рубрики» |
| **Страницы** | «О нас», «Авторы», «Журнал», «Главная» |
| **Медиафайлы** | картинки: обложки, иллюстрации к статьям |
| **Внешний вид → Меню** | что стоит в шапке и подвале |
| **Внешний вид → Настроить → Синтаксис** | почта, подписи в подвале, тексты-подводки |
| **Инструменты → Демо-контент** | залить макетное наполнение заново |

Комментариев в меню нет — они выключены совсем: издательству они не нужны, а оформления для них в дизайне не предусмотрено.

### Как устроена любая страница редактирования

Сверху — **заголовок**, под ним — **основной текст** (это «блочный редактор»). Ниже — **наши поля**: цена, ссылки на магазины, выходные данные и прочее. Справа — кнопка **«Опубликовать»** и колонка с настройками.

Блочный редактор — это текст, разбитый на блоки. Нажимаешь Enter — начинается новый абзац-блок. Чтобы сделать заголовок или цитату, нажми `+` слева от блока.

**Блоков в списке нарочно мало** — только абзац, заголовок, список, цитата и картинка. Все остальные блоки WordPress (колонки, галереи, кнопки, обложки) в нашем дизайне не оформлены и выглядели бы на сайте чужеродно, поэтому их убрали из меню. Если однажды понадобится что-то ещё — это добавляется одной строчкой в теме.

## 4. Как добавить книгу

**Книги → Добавить книгу.**

### Заголовок и текст

- **Заголовок** — название книги, без имени автора и без кавычек: `Хор одиночек`.
- **Основной текст** — раздел «О книге» на странице книги. Обычные абзацы.

### Справа, в колонке

- **Авторы** — поставь галочку. Автора нет в списке? Внизу блока «Добавить новый автор». Пиши как на обложке: `Вера Ланская`, имя и фамилия.
- **Жанры** — галочка: роман, стихи, рассказы, повесть, автофикшн, проза.
- **Изображение книги** — сюда грузится настоящая обложка-картинка, когда она есть. Пока не загружена, обложка рисуется из полей (см. ниже).
- **Цитата** (она же «Отрывок») — одна фраза, которая стоит под названием на главной и на странице книги. Например: *Роман о доме на окраине, где сорок квартир молчат по-разному.* Если не заполнить, блок просто будет без неё.

### Блок «Карточка книги»

| Поле | Что писать |
|---|---|
| Год издания | `2026`. По нему книги группируются в каталоге |
| Статус | «В продаже» или «Готовим к печати» |
| Когда выйдет | `Октябрь 2026` — показывается вместо цены у книги, которая ещё готовится |
| Ярлык на карточке | `Новинка · август 2026`. Пусто — тема сама поставит «Жанр · Год» |
| Ярлык красным | так помечают новинку |

### Блок «Обложка»

Это про **нарисованную** обложку — ту, что собирается из цвета и текста, без картинки. Если загрузишь настоящую обложку в «Изображение книги», эти поля не понадобятся.

| Поле | Что писать |
|---|---|
| Стиль обложки | одна из одиннадцати палитр: киноварь, чёрная, индиго, зелень, бордо, табачная, олива, слоновая кость, песок, стекло, белая |
| Верхняя строка | обычно имя автора. Пусто — подставится само |
| Название на обложке | **каждая строка здесь — отдельная строка на обложке.** `*слово*` со звёздочками — полужирным |
| Инициал | одна буква или знак. Работает только у палитр «зелень» и «белая» |
| Нижняя строка | `роман`, `проза · 416 с.` |
| Нижнюю строку курсивом | галочка |
| Красная «;» в конце | фирменный знак в конце названия |

**Что важно знать про палитры.** У каждой свой характер, и не всякое название в неё влезет:

- **Киноварь** — первое слово набирается очень крупно (как «ХОР»), остальное мельче. Годится, когда первое слово короткое. Длинное первое слово вылезет за край.
- **Индиго** — название идёт вертикально по корешку **одной строкой без переносов.** Только для коротких названий, в два-три слова максимум.
- **Песок** — ровно три строки разного начертания. Дашь больше — лишнее склеится в третью.
- **Зелень** и **белая** — ждут инициала. Без него будет пустовато.
- Все остальные просто ставят строки одну под другой.

Если сомневаешься — возьми «бордо» или «табачную»: они принимают почти любой текст.

### Блок «Покупка»

Цена в рублях (просто число: `780`), ссылки на Ozon, Wildberries, Лабиринт, цена и ссылка на электронную версию, примечание под кнопками. **Пустая ссылка — кнопки не будет.** Сейчас во всех книгах стоят заглушки `#`, их надо заменить настоящими.

### Блок «Выходные данные»

Серия, объём, формат, бумага, тираж, ISBN, возрастная маркировка, художник обложки. Пустые строки на странице не показываются — заполняй что есть.

### Блок «Фрагмент и пресса»

- **Фрагмент книги** — отрывок для страницы. Абзацы разделяй пустой строкой. Первая буква станет буквицей автоматически.
- **Ссылка «читать целиком»** — если фрагмент есть где-то ещё.
- **Цитата из прессы** и **кто сказал**.

### Блок «На главной» (справа)

- **Показывать на главной** — галочка.
- **Порядок** — число. Меньше число — выше в мозаике.

Дальше — **«Опубликовать»**. Книга появится по адресу `/books/<слаг>/`. Слаг (кусок адреса) WordPress делает из названия сам, но у русских названий он получается кракозяброй — **поправь его вручную**: справа, «Ссылка» → впиши латиницей, например `hor-odinochek`.

### Об авторе

Биография автора пишется **не в книге, а в самом авторе**: Книги → Авторы → нажать на имя → поле «Описание». Так она пишется один раз и показывается на странице каждой его книги.

Там же есть поле «Фамилия» — оно нужно только если сортировка в списке авторов ошиблась. По умолчанию фамилией считается последнее слово имени, и для обычных «Имя Фамилия» это работает.

## 5. Как добавить материал в журнал

**Журнал → Добавить материал.**

- **Заголовок** — заголовок статьи.
- **Основной текст** — сама статья. Подзаголовки внутри делай блоком «Заголовок» (он вставит `h2`). Цитаты — блоком «Цитата», на сайте у неё будет красная черта слева.
- **Цитата/Отрывок** (справа) — дек, короткая подводка под заголовком. **Заполняй обязательно:** дек стоит и на главной, и в ленте журнала.
- **Рубрики** (справа) — Эссе, Интервью, Рецензия, Хроника. Одна на материал.

Блок «Материал»:

| Поле | Что писать |
|---|---|
| Автор материала | `Нина Аверьянова` |
| Должность | `главный редактор` |
| Время чтения | `12 минут` |
| Врезка «книга по теме» | выбери книгу из списка — её карточка встанет в середину статьи |
| Строчка об авторе в конце | мелким шрифтом под текстом |

Блок «На главной» — то же, что у книг.

Адрес получится `/journal/<слаг>/`. Слаг тоже поправь на латиницу.

## 6. Как править «О нас»

**Страницы → Синтаксис;**

Обычные разделы («Что мы делаем», «Рукописи», «Магазинам») пишутся прямо в тексте: ставишь блок «Заголовок» — он становится красным ярлыком слева, а абзацы под ним — текстом справа.

А четыре блока — манифест, принципы, цифры и люди — устроены иначе: они не абзацы, а сетки, поэтому их содержимое лежит в полях под редактором, а в тексте стоит **пометка в квадратных скобках**:

```
[манифест]    крупная фраза в начале
[принципы]    нумерованные карточки
[цифры]       крупные числа с подписями
[люди]        имена и роли
[контакты]    крупные ссылки (почта, телеграм)
```

Пометка — это место, где блок появится. Само содержимое правится ниже, в блоке «Блоки страницы». Формат простой: **одна строка — один пункт, части через вертикальную черту `|`**:

```
Один редактор на книгу | От самотёка до типографии книгу ведёт один человек.
Никакой серии ради серии | Мы не добираем названия, чтобы закрыть план.
```

```
2019 | год, когда вышла первая книга
47 | книг в каталоге
```

В манифесте `*звёздочки*` красят слова в красный курсив.

Хочешь поменять порядок разделов — просто передвинь пометку вместе с её заголовком.

## 7. Как собирается главная

Главная — это мозаика: этажи разной высоты, в каждом от одного до четырёх блоков.

Правило простое: в мозаику попадает всё, у чего стоит галочка **«Показывать на главной»**, в порядке поля **«Порядок»**. Дальше тема режет этот список на этажи по схеме **1 · 3 · 2 · 4** и дальше по кругу: первый блок во всю ширину, потом ряд из трёх, потом из двух, потом из четырёх.

То есть порядок 1–10 даст ровно ту главную, что в макете. Хочешь другую компоновку — меняй числа в «Порядке».

Последний этаж («Об издательстве») стоит всегда, его тексты — в **Внешний вид → Настроить → Синтаксис**.

**Одна вещь, которую нельзя автоматизировать.** Блок книги высокий (в нём обложка), блок заметки — низкий. Если рядом с высокими книгами оказывается заметка без дека, она виснет в пустоте. Поэтому: **у заметок, которые ставишь на главную, всегда заполняй «Цитату/Отрывок»**. Тема за этим следить не умеет — это редакторское решение.

## 8. Меню, подвал, настройки

**Внешний вид → Меню.** Три меню:

- *Меню сайта* — то, что в шапке;
- *Подвал* — разделы внизу;
- *Соцсети* — телеграм, ВКонтакте, ютуб (в них сейчас стоят заглушки `#`).

Добавить пункт: слева выбери страницу или впиши произвольную ссылку, нажми «Добавить в меню», перетащи в нужное место, «Сохранить меню».

**Внешний вид → Настроить → Синтаксис** — почта, подпись под логотипом, строчка про самотёк, копирайт, подводки к каталогу, журналу и списку авторов, тексты блока «Об издательстве» на главной.

## 9. Настоящие обложки вместо нарисованных

Нарисованные CSS-обложки — не заглушка, а часть стиля: они останутся для книг, у которых готовой обложки нет.

Когда обложка есть: открой книгу → справа **«Изображение книги»** → загрузи файл. Тема сама подставит его вместо нарисованной, обрезав в пропорцию 5:7.

Требования к файлу: **пропорция 5:7** (например 1000×1400), JPEG или PNG, до 500 КБ. Если пропорция другая — картинку обрежет по центру.

## 10. Чего лучше не делать

- **Не ставь плагины наугад.** Каждый плагин добавляет свой CSS и JS, а у нас на странице сейчас ноль скриптов. Нужен плагин — сначала обсудим зачем.
- **Не меняй тему** в «Внешний вид → Темы». Другая тема — другой сайт: наша вёрстка живёт только в теме «Синтаксис».
- **Не редактируй файлы темы через админку** («Внешний вид → Редактор файлов»). Файлы лежат в гите; правка через админку не попадёт в репозиторий, и следующая же выгрузка её сотрёт.
- **Не удаляй страницы** «Главная» и «Журнал» — на них завязаны настройки «что показывать на главной».
- **Не включай комментарии.** Оформления для них нет.

## 11. Где что лежит

```
~/projects/syntaxis/                    ← репозиторий, тут работает гит
  index.html, books.html, …             ← старый статический макет (см. ниже)
  styles.css                            ← его стили
  wp-content/themes/sintaksis/          ← ТЕМА, всё живое здесь
    style.css                           ← вся вёрстка сайта
    functions.php                       ← настройка темы
    front-page.php, single-book.php…    ← шаблоны страниц
    inc/                                ← типы контента, поля, уборка за WP
    template-parts/                     ← обложка, блоки мозаики, карточки

~/projects/syntaxis-wp/                 ← сам WordPress, в гит не входит
  wp-admin/, wp-includes/               ← движок
  wp-content/themes/sintaksis           ← симлинк на тему из репозитория
  db/                                   ← база
  start.command                         ← запуск
```

**Про старый макет.** Файлы `index.html`, `books.html` и остальные остались на месте — они открываются двойным кликом и показывают исходный дизайн. Но живой сайт теперь собирается темой, и стили у него свои: `wp-content/themes/sintaksis/style.css`. Правишь оформление — правь его, а не корневой `styles.css`. Когда сайт уедет на хостинг, макет можно удалить или оставить в архиве.

## 12. Если что-то пошло не так

**Сайт не открывается, «connection refused».** Не запущен сервер — `start.command`.

**Белый экран.** Ошибка в PHP. Она записана в `~/projects/syntaxis-wp/wp-content/debug.log` — открой его, там последняя строка объясняет причину.

**Страница отдаёт 404, хотя она есть.** Слетели «постоянные ссылки». Лечится так: Настройки → Постоянные ссылки → «Сохранить изменения» (ничего не меняя).

**Правки в CSS не видны.** Обнови страницу с `Cmd+Shift+R`.

**Хочу вернуть демо-контент.** Инструменты → Демо-контент → кнопка. То, что уже создано, не тронется; удалённое вернётся.

**Совсем всё сломал.** База лежит в `~/projects/syntaxis-wp/db/`. Удали папку `data`, и я подниму установку заново — тема в репозитории от этого не пострадает.
