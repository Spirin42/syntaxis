## 2. Надо до релиза, но не блокирует

### 2.1 Шрифты — увезти к себе

Сейчас Piazzolla и Golos Text грузятся с `fonts.googleapis.com`. Две причины это поменять:

- **Юридическая.** Загрузка шрифта передаёт IP посетителя на серверы Google, то есть за границу. Для российского сайта это трансграничная передача персональных данных со всеми вытекающими из 152-ФЗ
- **Практическая.** Нет интернета до Google — шрифты падают на Georgia и Arial, и весь типографический замысел рассыпается

- [ ] Скачать оба шрифта, положить в `wp-content/themes/sintaksis/fonts/`, подключить через `@font-face` с `font-display: swap`, убрать `<link>` на Google

### 2.2 Мелочи, которых сейчас нет

- [ ] **Фавиконка файлом.** Сейчас нарисована прямо в адресе (data-URI) — работает, но в закладках и на телефоне выглядит бледно. Нужен `.png` 512×512 через Внешний вид → Настроить → Свойства сайта
- [ ] **Картинка для соцсетей (OG-image)** — 1200×630. Сейчас при отправке ссылки в телеграм превью будет пустым
- [ ] **Описания страниц (`meta description`)** — WordPress их сам не ставит. Либо плагин (Yoast, Rank Math), либо десять строк в теме. Плагин потянет свой CSS — лучше в теме
- [ ] **`sitemap.xml`** — WordPress отдаёт его сам по адресу `/wp-sitemap.xml`. Сейчас там 404, и это правильно: карта сайта отключается, пока стоит запрет индексации (п. 2.3). Проверить после того, как запрет снимешь
- [ ] **`robots.txt`** — проверить, что не запрещает индексацию

### 2.3 Включить индексацию

- [ ] **Настройки → Чтение → снять галочку «Попросить поисковые системы не индексировать сайт»**. Сейчас она стоит — это правильно для локальной копии и смертельно для боевого сайта
- [ ] Добавить сайт в Яндекс.Вебмастер

### 2.4 Аналитика

- [ ] **Яндекс.Метрика** — счётчик добавляется скриптом, то есть нарушает правило «без JS». Это осознанный размен: без счётчика непонятно, читают ли журнал. Ставить один тег в подвал, ничего больше
- [ ] Google Analytics для российского сайта не брать — та же трансграничная передача, что и со шрифтами

## 3. После запуска — чтобы не потерять сайт

- [ ] **Бэкапы.** База и папка `wp-content/uploads` — раз в неделю, автоматически. На шаред-хостинге обычно есть встроенные, проверить что включены и что из них реально можно восстановиться
- [ ] **Обновления WordPress.** Сейчас 7.0.2. Обновления безопасности ставить сразу, крупные версии — сначала на копии
- [ ] **Тема — в гите.** Все правки оформления делать в репозитории и выгружать на сервер, а не через админку. Иначе следующая выгрузка их сотрёт
- [ ] Выключить `WP_DEBUG` в `wp-config.php` на боевом сервере (в локальном он включён намеренно)
