# «Синтаксис» — сайт издательства

Статический сайт издательства современной русской литературы. Без сборки, фреймворков и JS — только HTML + CSS. Смотреть: `open index.html`.

**Это не телеграм-бот.** Серверные правила из `~/projects/CLAUDE.md` (деплой по scp, pkill, nohup) сюда не применяются. Куда деплоить сайт — ещё не решено. Git не инициализирован.

## Статус (2026-08-03)

Готова главная страница: `index.html` + `styles.css`. Всё остальное — планы (см. дорожную карту).

## Важно: весь контент — заглушки

Книги, авторы, материалы журнала, даты, цифры, почта `post@sintaksis.press` — вымышленные, для макета. Соцсети и почти все ссылки ведут в `href="#"`. Перед публикацией всё заменить на реальное; заглушки искать по `href="#"`.

## Дизайн-система

Референс, заданный владельцем: [slova-vne.com](https://slova-vne.com/) — журнальная типографика-первая вёрстка, рубрики-ярлыки, огромный шрифт с засечками, монохром. Наш сайт держит этот дух, но со своим лицом: чисто-белый фон, крупные обложки-галерея, один красный акцент.

### Токены (`:root` в styles.css)

| Токен | Значение | Зачем |
|---|---|---|
| `--paper` | `#FFFFFF` | фон |
| `--ink` | `#16130E` | текст, линейки секций, подвал |
| `--ink-soft` | `#6E675C` | подписи, деки |
| `--rule` | `#E4E0D6` | волосяные линейки |
| `--accent` | `#E0361A` | киноварь: «;» в логотипе, номера секций, рубрики, ховеры |
| `--accent-warm` | `#F94A26` | красный на тёмных плашках (чёрная обложка, подвал) |

Красного намеренно мало — только пунктуация и служебное.

### Шрифты (Google Fonts, вариативные, полная кириллица)

- **Piazzolla** (`--serif`) — все заголовки, названия книг, обложки, логотип. Резкая современная антиква, на огромных кеглях включается оптический размер.
- **Golos Text** (`--sans`) — навигация, ярлыки, подписи, основной текст. Без интернета падают на Georgia/Arial — страница остаётся читаемой.

Логотип — слово «синтаксис» строчными + красная точка с запятой (`.wordmark__mark`). Точка с запятой = фирменный знак, повторяется на обложках («синтаксис;») и в подвале.

### Компоненты

- `.chip` — ярлык в рамке (жанр · год); `.chip--accent` — красный (герой).
- `.rubric` — красная рубрика капсом (журнал, «об издательстве»).
- `.text-btn` — подчёркнутая ссылка-кнопка со стрелкой `.arr` (стрелка уезжает на ховере).
- `.section__head` — шапка секции: чёрная линейка сверху, заголовок-антиква с красным номером `<sup>`, ссылка «Все …» справа.
- `.cover` — **обложки нарисованы чистым CSS**, картинок на сайте нет вообще. База: `aspect-ratio: 5/7`, `container-type: inline-size`, вся типографика внутри в `cqi` — обложка без изменений масштабируется под любую колонку (герой, витрина, будущие карточки). У каждой книги свой модификатор: `.cover--hor` (киноварь, конструктивизм), `--vnutr` (стихи, рамка), `--nichey` (чёрный автофикшн), `--sever` (индиго, вертикальный корешок), `--tishe` (зелёный, инициал), `--slovar` (песок, словарная статья). Новая книга = новый модификатор по аналогии; светлым обложкам добавлять `.cover--light` (волосяная обводка). Для каждого размера шрифта в обложке есть px-фолбэк на случай браузера без container queries.
- `.books-grid` — витрина: 12 колонок, ручная расстановка `.place-a…e` + разновысокие сдвиги `margin-top` — журнальный «разброс». Карточка: обложка → чип → автор капсом → крупное название.
- `.journal-grid` — фича (7 колонок) + боковой список из трёх материалов (5 колонок) с линейками.
- `.soon-row` — табличные строки анонсов: срок / автор / название / жанр.

### Брейкпоинты

`1100` (витрина в 2 колонки) → `880` (герой и журнал в столбик) → `760` (анонсы и подвал в столбик) → `620` (всё в одну колонку, «Авторы» прячется из шапки).

## Конвенции

- Язык контента — русский, типографика по-взрослому: «ёлочки», „лапки“ внутри цитат, тире `—`, буква ё.
- JS не добавлять, пока задача решается CSS.
- Классы БЭМ-подобные: `блок__элемент`, модификатор через `--`.
- Новые страницы переиспользуют `styles.css`; специфичные стили — в конец файла со своим комментарием-шапкой.
