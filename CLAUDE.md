# «Синтаксис» — сайт издательства

Сайт издательства современной русской литературы **на WordPress**. Без сборки, фреймворков и JS — только PHP-шаблоны + CSS; на странице ноль тегов `<script>`, и так и должно остаться.

**Это не телеграм-бот.** Серверные правила из `~/projects/CLAUDE.md` (деплой по scp, pkill, nohup) сюда не применяются. Куда деплоить сайт — ещё не решено; см. `CHECKLIST.md`.

Git: репозиторий инициализирован, приватный ремоут — https://github.com/Spirin42/syntaxis. Коммиты и пуш прямо в `main` (как во всех проектах), сообщения короткие на русском.

Два документа для владельца: **`WORDPRESS.md`** — как пользоваться админкой (он WordPress раньше не видел), **`CHECKLIST.md`** — что осталось до релиза.

## Статус (2026-08-05)

Сайт переведён со статики на WordPress. Вёрстка перенесена в тему **один в один**: все одиннадцать CSS-обложек и структура главной совпадают со старым макетом посимвольно (проверено диффом сгенерированного HTML против `books.html` и `index.html`).

**Статический макет остался в репозитории** (`index.html`, `books.html`, `authors.html`, `about.html`, `books/`, `journal/`, `styles.css`) — он открывается двойным кликом и служит эталоном дизайна. Но живой сайт — это тема, и **актуальный CSS теперь `wp-content/themes/sintaksis/style.css`**, а не корневой `styles.css`. Правишь оформление — правь в теме. Корневой `styles.css` — замороженная копия макета.

Локальная установка WordPress 7.0.2 (ru_RU) лежит **вне репозитория**: `~/projects/syntaxis-wp/`. Тема подключена туда симлинком, база — свой mysqld на порту 3307 с данными в `~/projects/syntaxis-wp/db/` (чужой MySQL пользователя не трогается). Запуск — `~/projects/syntaxis-wp/start.command`, сайт на `localhost:8080`, админка `admin` / `sintaksis`.

## Дизайн-система

Референс, заданный владельцем: [slova-vne.com](https://slova-vne.com/) — журнальная типографика-первая вёрстка, рубрики-ярлыки, огромный шрифт с засечками, монохром. Наш сайт держит этот дух, но со своим лицом: чисто-белый фон, крупные CSS-обложки, один красный акцент. Структура ленты — от «Медузы»: этажи разновеликих блоков с видимыми границами.

### Шрифты (Google Fonts, вариативные, полная кириллица)

- **Piazzolla** (`--serif`) — заголовки блоков, названия книг, обложки, логотип.
- **Golos Text** (`--sans`) — навигация, ярлыки, подписи, деки, кнопки. Без интернета падают на Georgia/Arial.

Логотип — слово «синтаксис» строчными + красная точка с запятой (`.wordmark__mark`). Точка с запятой = фирменный знак, повторяется на обложках («синтаксис;») и в подвале.

## Мозаика: этажи и блоки

Главная = `.mosaic` — вертикальная стопка **этажей**; этаж (`.floor`) — ряд **блоков**; блок (`.block`) — книга, заметка журнала или манифест издательства. Компоновка этажей — ручная, как полоса газеты (сейчас: 1 · 3 · 2 · 4 · 1 блоков).

- **Границы блоков.** Все линии мозаики — фон `.mosaic` цвета `--rule`, просвечивающий сквозь 1px-зазоры (`gap: 1px`) между белыми блоками. Границы каждого блока видны всегда и всегда ровно 1px — ничего не рисуется бордерами блоков, двойных линий не бывает.
- **Сколько блоков в ряду.** Этаж — `flex-wrap`, ширину задаёт `--basis` (`.floor--2` → 460px, `--3` → 320px, `--4` → 250px; `--1` — во всю ширину). Не влезли — переносятся, перенесённый «хвост» растягивается на весь ряд. `.floor--1` дополнительно даёт блокам увеличенный паддинг.
- **Блок книги** (`.block--book` → внутри обёртка `.book`): обложка + тело (`.book__body`: чип жанра, автор капсом, название, опционально `.dek`, ряд покупки). Каждый `.block` — контейнер (`container-type: inline-size`); при ширине блока ≥ 520px `.book` перестраивается контейнер-квери в горизонталь: текст слева, обложка справа (капом 34cqi ≤ 470px), тело центрируется по вертикали. Узкий блок — колонка: обложка сверху, покупка прижата к низу (в ряду одинаково высоких карточек кнопки стоят по одной линии). Кегли названия/автора — в `cqi`, т.е. от ширины самого блока, у каждого cqi-кегля есть px/vw-фолбэк строчкой выше.
- **Ряд покупки** (`.buy`): цена (`.buy__price`) + кнопки-магазины (`.buy__link` — Ozon, Wildberries, Лабиринт; у новинки ещё «Электронная»). Пока это заглушки `href="#"`; решение о реальной схеме продажи — в дорожной карте.
- **Блок заметки** (`.block--note`): рубрика капсом (`.rubric`), заголовок-антиква (`.note__title`, кегль в cqi), `.dek`, дата (`.meta`). Контент центрируется по вертикали — заметка без обложки в ряду высоких книжных блоков ведёт себя как цитата.
- **Блок «об издательстве»** (`.block--about`, `id="about"`): рубрика, крупная цитата (`.about__quote`), подводка, кнопка «Манифест» (`.text-btn`).
- Прочая мелкая типографика: `.chip` (ярлык в рамке, `--accent` — красный), `.rubric`, `.meta`, `.dek`, `.text-btn` со стрелкой `.arr`.

### Обложки

**Обложки нарисованы чистым CSS**, картинок на сайте нет. База `.cover`: `aspect-ratio: 5/7`, `container-type: inline-size`, типографика в `cqi` — обложка масштабируется под любую ширину колонки. Модификаторы: `.cover--hor` (киноварь, конструктивизм), `--vnutr` (стихи, рамка), `--nichey` (чёрный автофикшн), `--sever` (индиго, вертикальный корешок), `--tishe` (зелень, инициал), `--slovar` (песок, словарная статья), `--polyn` (олива, курсив), `--kabinet` (бордо, линейки), `--stekla` (стекло, тонкий шрифт), `--tabak` (табачный, разрядка), `--pustoe` (белая, знак ∅). Новая книга = новый модификатор по аналогии; светлым обложкам добавлять `.cover--light` (волосяная обводка). У каждого cqi-кегля есть px-фолбэк.

**Ловушка `cqi` + `writing-mode: vertical-rl`** (вертикаль на `--sever`): у вертикального текста inline-ось вертикальна, поэтому `cqi` у него меряет **высоту**, которую обложка (inline-size-контейнер) не контейнирует, — единица молча падает на размер вьюпорта. Для таких элементов использовать `cqb` (у vertical-rl это ширина обложки). Уже поймано и починено один раз — не переписывать обратно на cqi.

### Адаптивность: без брейкпоинтов

Медиазапросов по ширине в проекте **нет** (единственный `@media` — `prefers-reduced-motion`), и добавлять их не надо: каждый элемент отзывчив сам по себе. Инструменты: перенос флексов (этажи, шапка, подвал, ряд покупки), `clamp()` с vw для отступов и кеглей, `grid-template-columns: repeat(auto-fill, minmax(…, 1fr))` для сеток внутренних страниц, контейнер-квери для перестройки блока книги. Любое новое на сайте делать так же — responsive by design.

## Внутренние страницы

Ниже упомянуты html-файлы макета; вот чем они стали в теме:

| Макет | Шаблон темы |
|---|---|
| `index.html` | `front-page.php` |
| `books.html` | `archive-book.php`, а `taxonomy-genre.php` его подключает |
| `books/hor-odinochek.html` | `single-book.php` |
| `journal/medlennoe-chtenie.html` | `single.php` |
| `authors.html` | `page-authors.php` |
| `about.html` | `page.php` + подстановки |
| — (нового нет в макете) | `home.php` (лента журнала), `category.php`, `search.php`, `404.php`, `index.php` (архивы по дате и автору) |

**Почему `archive-book.php`, а не `archive.php`.** Файл `archive.php` перехватил бы заодно архивы по дате и по автору — и журнальные записи вышли бы книжными карточками с выдуманными обложками. Каталог должен называться `archive-book.php`; жанры подключают его через `get_template_part`, а дата и автор проваливаются в `index.php` с лентой журнала. Не переименовывать обратно.

Главная — мозаика с видимыми границами; внутренние страницы наоборот воздушные: белое поле, волосяные разделители, текст прижат влево. Общие детали шапки страницы: `.crumbs` (хлебные крошки), `.page-head` (рубрика + огромный `.page-head__title` + `.page-head__sub`), `.section` (флекс: ярлык `.section__label` слева, `.section__body` справа; узко — ярлык встаёт сверху), `.prose`, `.lead-serif`, полоса «читайте дальше» `.more`. Текущий пункт меню помечается `aria-current="page"` — перед ним появляется красная точка.

- **Страница книги** (`books/hor-odinochek.html`): `.bookpage` — обложка (`.bookpage__aside`, не липкая) и текст рядом, при переносе обложка сверху. Дальше секциями: о книге, фрагмент (`.excerpt` — антиква, буквица, абзацный отступ), выходные данные (`.specs`), об авторе, пресса, `.more`. Крупный ряд покупки — `.buy.buy--lg`, первая кнопка `.buy__link--solid` (чёрная плашка).
- **Статья** (`journal/medlennoe-chtenie.html`): `.article__head` (рубрика, заголовок, дек, `.article__byline`), затем `.article__body` — колонка в 68ch, красная буквица у первого абзаца, `h2`, `blockquote` с красной чертой, врезка «книга по теме» (`.inset`), `.article__end` про автора.
- **Каталог** (`books.html`): грид `.catalog` из `.card`, разбитый подзаголовками `.catalog-split` (`grid-column: 1 / -1`) по годам; у книги в печати вместо цены `.card__soon`.
- **Авторы** (`authors.html`): `.authors__group` — красная литера + `.authors__list` с именами антиквой. Только имена, без фотографий (решение владельца). `.is-soon` — приглушённое имя автора, чья книга ещё готовится.
- **О нас** (`about.html`): `.manifesto` (крупная цитата), `.tenets` (нумерованные принципы), `.figures` (цифры), `.people` (имя + роль), `.contact-line`.

**Ловушка сеток с линиями.** У `.tenets` и `.specs` линии рисуются не фоном-подложкой, как в мозаике, а `outline: 1px` на каждой ячейке. При `auto-fill` число колонок заранее неизвестно, и «хвост» последнего ряда с фоном-подложкой светился бы серым прямоугольником. Соседние outline'ы накладываются в 1px-зазоре — линия остаётся одна. В мозаике на главной ячейки всегда заполнены, там фон-подложка правильна.

## Тема WordPress (`wp-content/themes/sintaksis/`)

Тема классическая (PHP-шаблоны), не блочная: блочная тема воевала бы с ручной типографикой на `clamp()` и `cqi`.

**Модель контента.** Тип `book` (архив `/books/`, страница `/books/<слаг>/`); таксономии `book_author` (без публичных адресов — у авторов нет своих страниц, это решение владельца) и `genre` (архив `/genre/<слаг>/` рисуется каталогом). Журнал — **встроенные записи**, переименованные фильтрами `post_type_labels_post` и `taxonomy_labels_category`: так бесплатно достаются рубрики, RSS, поиск. Постоянные ссылки — `/journal/%postname%/`, база рубрик `rubrika`.

**Поля** описаны одним массивом в `inc/meta-boxes.php` (`sx_field_groups()`) и рисуются общим кодом; ключ `foo` лежит в базе как `_sx_foo`. Плагинов вроде ACF нет и не надо.

| Файл | Что делает |
|---|---|
| `inc/post-types.php` | типы и таксономии, колонки в списках админки |
| `inc/meta-boxes.php` | все поля книги, материала и страницы |
| `inc/helpers.php` | обложки-палитры, склонения, разбор контента на секции, раскладка этажей, walker меню |
| `inc/shortcodes.php` | `[манифест]`, `[принципы]`, `[цифры]`, `[люди]`, `[контакты]` для «О нас» |
| `inc/cleanup.php` | снимает CSS блочного редактора, глобальные стили, эмодзи, `wp-embed`, комментарии; сужает список блоков |
| `inc/customizer.php` | тексты подвала и подводки разделов |
| `inc/demo-content.php` | импорт макетного наполнения |

**Ловушка с глобальными стилями.** `wp_dequeue_style('global-styles')` не работает: WordPress ставит их дважды — на `wp_enqueue_scripts` и ещё раз на `wp_footer` (priority 1), откуда «поднимает» в `<head>`. Снимаются только удалением обоих обработчиков (`remove_action`), см. `inc/cleanup.php`. Не переписывать обратно на dequeue.

**Обложки в теме.** `template-parts/cover.php` собирает ту же разметку, что была в макете, из полей книги: одиннадцать палитр, у трёх особая раскладка названия (`lines2` — `.l1/.l2` киновари, `lines3` — `.w1/.w2/.w3` песка, `vert` — корешок индиго). `cover--light` жёстко привязан к четырём светлым палитрам, галочкой не задаётся. Есть загруженное «Изображение книги» — рисуется `<img class="cover cover--photo">`, CSS-обложка не используется.

**Мозаика главной.** В `front-page.php` берутся записи с `_sx_featured`, сортируются по `_sx_featured_order` и режутся `sx_pour_floors()` по схеме `[1,3,2,4]`. Неполный последний этаж безопасен — «хвост» ряда растягивается сам.

**Страницы.** `page.php` режет контент по `<h2>` на `.section` (ярлык слева, текст справа) — владелец просто пишет заголовок и абзацы. Сетки `.tenets/.figures/.people` не заворачиваются в `.prose`, чтобы не зажимать грид в 66ch.

## Конвенции

- Язык контента — русский, типографика по-взрослому: «ёлочки», „лапки“ внутри цитат, тире `—`, буква ё. Тексты в админке и подсказки к полям — тоже по-русски и без жаргона: владелец WordPress раньше не видел.
- JS не добавлять, пока задача решается CSS. Сейчас на странице ноль `<script>` — это проверяемое свойство, не пожелание.
- Классы БЭМ-подобные: `блок__элемент`, модификатор через `--`.
- Новый CSS — в конец `wp-content/themes/sintaksis/style.css` со своим комментарием-шапкой.
- Медиазапросов по ширине нет: единственные `@media` — `prefers-reduced-motion` и брейкпоинт админ-панели WordPress (её видит только залогиненный редактор).
- Разрешённые блоки редактора сужены до абзаца, заголовка, списка, цитаты, картинки и HTML. Понадобится ещё один — добавлять осознанно и сразу писать под него стили.
- Шапка и подвал теперь общие (`header.php` / `footer.php`), копировать по файлам больше не надо.
- Инлайновых `style=` в разметке нет — любой отступ через класс в CSS. Исключение — служебный CSS админки в `inc/meta-boxes.php`, на сайт он не попадает.
- Демо-импортёр держать идемпотентным: он же служит «вернуть как было».
