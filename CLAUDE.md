# «Синтаксис» — сайт издательства

Статический сайт издательства современной русской литературы. Без сборки, фреймворков и JS — только HTML + CSS. Смотреть: `open index.html`.

**Это не телеграм-бот.** Серверные правила из `~/projects/CLAUDE.md` (деплой по scp, pkill, nohup) сюда не применяются. Куда деплоить сайт — ещё не решено.

Git: репозиторий инициализирован, приватный ремоут — https://github.com/Spirin42/syntaxis. Коммиты и пуш прямо в `main` (как во всех проектах), сообщения короткие на русском.

## Статус (2026-08-04)

Главная (`index.html` + `styles.css`) переделана из «секций» в **мозаику этажей и блоков** (по образцу «Медузы» — meduza.io, идея владельца). Секций «Каталог», «Журнал», «Готовим к печати» больше нет: книги и материалы журнала перемешаны в одной ленте. Всё остальное — планы (см. дорожную карту).

## Важно: весь контент — заглушки

Книги, авторы, заметки, даты, цены, почта `post@sintaksis.press` — вымышленные, для макета. Кнопки покупки (Ozon, Wildberries, Лабиринт), соцсети и почти все ссылки ведут в `href="#"`. Перед публикацией всё заменить на реальное; заглушки искать по `href="#"`.

## Дизайн-система

Референс, заданный владельцем: [slova-vne.com](https://slova-vne.com/) — журнальная типографика-первая вёрстка, рубрики-ярлыки, огромный шрифт с засечками, монохром. Наш сайт держит этот дух, но со своим лицом: чисто-белый фон, крупные CSS-обложки, один красный акцент. Структура ленты — от «Медузы»: этажи разновеликих блоков с видимыми границами.

### Токены (`:root` в styles.css)

| Токен | Значение | Зачем |
|---|---|---|
| `--paper` | `#FFFFFF` | фон |
| `--ink` | `#16130E` | текст, подвал |
| `--ink-soft` | `#6E675C` | подписи, деки |
| `--rule` | `#E4E0D6` | все линии мозаики |
| `--accent` | `#E0361A` | киноварь: «;» в логотипе, рубрики, ховеры |
| `--accent-warm` | `#F94A26` | красный на тёмных плашках (чёрная обложка, подвал) |

Красного намеренно мало — только пунктуация и служебное.

### Шрифты (Google Fonts, вариативные, полная кириллица)

- **Piazzolla** (`--serif`) — заголовки блоков, названия книг, обложки, логотип.
- **Golos Text** (`--sans`) — навигация, ярлыки, подписи, деки, кнопки. Без интернета падают на Georgia/Arial.

Логотип — слово «синтаксис» строчными + красная точка с запятой (`.wordmark__mark`). Точка с запятой = фирменный знак, повторяется на обложках («синтаксис;») и в подвале.

## Мозаика: этажи и блоки

Главная = `.mosaic` — вертикальная стопка **этажей**; этаж (`.floor`) — ряд **блоков**; блок (`.block`) — книга, заметка журнала или манифест издательства. Компоновка этажей — ручная, как полоса газеты (сейчас: 1 · 3 · 2 · 4 · 1 блоков).

- **Границы блоков.** Все линии мозаики — фон `.mosaic` цвета `--rule`, просвечивающий сквозь 1px-зазоры (`gap: 1px`) между белыми блоками. Границы каждого блока видны всегда и всегда ровно 1px — ничего не рисуется бордерами блоков, двойных линий не бывает.
- **Сколько блоков в ряду.** Этаж — `flex-wrap`, ширину задаёт `--basis` (`.floor--2` → 460px, `--3` → 320px, `--4` → 250px; `--1` — во всю ширину). Не влезли — переносятся, перенесённый «хвост» растягивается на весь ряд. `.floor--1` дополнительно даёт блокам увеличенный паддинг.
- **Блок книги** (`.block--book` → внутри обёртка `.book`): обложка + тело (`.book__body`: чип жанра, автор капсом, название, опционально `.dek`, ряд покупки). Каждый `.block` — контейнер (`container-type: inline-size`); при ширине блока ≥ 520px `.book` перестраивается контейнер-квери в горизонталь: текст слева, обложка справа (капом 34cqi ≤ 470px), тело центрируется по вертикали. Узкий блок — колонка: обложка сверху, покупка прижата к низу (в ряду одинаково высоких карточек кнопки стоят по одной линии). Кегли названия/автора — в `cqi`, т.е. от ширины самого блока, у каждого cqi-кегля есть px/vw-фолбэк строчкой выше.
- **Ряд покупки** (`.buy`): цена (`.buy__price`) + кнопки-магазины (`.buy__link` — Ozon, Wildberries, Лабиринт; у новинки ещё «Электронная»). Пока это заглушки `href="#"`; решение о реальной схеме продажи — в дорожной карте.
- **Блок заметки** (`.block--note`): рубрика капсом (`.rubric`), заголовок-антиква (`.note__title`, кегль в cqi), `.dek`, дата (`.meta`). Контент центрируется по вертикали — заметка без обложки в ряду высоких книжных блоков ведёт себя как цитата.
- **Блок «об издательстве»** (`.block--about`, `id="about"`): рубрика, крупная цитата (`.about__quote`), подводка, кнопка «Манифест» (`.text-btn`).
- Прочая мелкая типографика: `.chip` (ярлык в рамке, `--accent` — красный), `.rubric`, `.meta`, `.dek`, `.text-btn` со стрелкой `.arr`.

### Обложки

**Обложки нарисованы чистым CSS**, картинок на сайте нет. База `.cover`: `aspect-ratio: 5/7`, `container-type: inline-size`, типографика в `cqi` — обложка масштабируется под любую ширину колонки. Модификаторы: `.cover--hor` (киноварь, конструктивизм), `--vnutr` (стихи, рамка), `--nichey` (чёрный автофикшн), `--sever` (индиго, вертикальный корешок), `--tishe` (зелень, инициал), `--slovar` (песок, словарная статья). Новая книга = новый модификатор по аналогии; светлым обложкам добавлять `.cover--light` (волосяная обводка). У каждого cqi-кегля есть px-фолбэк.

**Ловушка `cqi` + `writing-mode: vertical-rl`** (вертикаль на `--sever`): у вертикального текста inline-ось вертикальна, поэтому `cqi` у него меряет **высоту**, которую обложка (inline-size-контейнер) не контейнирует, — единица молча падает на размер вьюпорта. Для таких элементов использовать `cqb` (у vertical-rl это ширина обложки). Уже поймано и починено один раз — не переписывать обратно на cqi.

### Адаптивность: без брейкпоинтов

Медиазапросов по ширине в проекте **нет** (единственный `@media` — `prefers-reduced-motion`), и добавлять их не надо: каждый элемент отзывчив сам по себе. Инструменты: перенос флексов (этажи, шапка, подвал, ряд покупки), `clamp()` с vw для отступов и кеглей, контейнер-квери для перестройки блока книги. Любое новое на сайте делать так же — responsive by design.

## Дорожная карта (по приоритету, от владельца)

1. **Страницы книг** — шаблон: большая обложка, аннотация, фрагмент, выходные данные, «Купить». Решить схему урлов (например, `books/hor-odinochek.html`) и завести шаблон, из которого штампуются остальные.
2. **Продажа по-настоящему** — кнопки в блоках уже стоят (цена + магазины, заглушки). Решить: свой приём оплаты vs ссылки на магазины, проставить реальные урлы и цены; те же кнопки использовать на страницах книг.
3. **Страницы авторов** + снять заглушку «Авторы» в навигации.
4. **Каталог** (все книги) и **журнал** (лента материалов) как отдельные страницы — тогда же оживить ссылки «Книги» и «Журнал» в шапке и подвале (сейчас `href="#"` с `title="Раздел готовится"`).
5. **Реальные обложки-картинки**: класть в `covers/`, в блоке менять `div.cover` на `<img>` с тем же `aspect-ratio: 5/7`. CSS-обложки оставить как стиль для книг без готовой обложки.
6. Соцссылки и почта в подвале — проставить реальные. OG-картинка, favicon-файл вместо data-URI, счётчик посещений.

## Конвенции

- Язык контента — русский, типографика по-взрослому: «ёлочки», „лапки“ внутри цитат, тире `—`, буква ё.
- JS не добавлять, пока задача решается CSS.
- Классы БЭМ-подобные: `блок__элемент`, модификатор через `--`.
- Новые страницы переиспользуют `styles.css`; специфичные стили — в конец файла со своим комментарием-шапкой.
- Новый этаж на главной: `<div class="floor floor--N">` + готовые блоки; следить, чтобы соседями высоких книжных блоков были заметки с деком (иначе заметка повиснет в пустоте).
